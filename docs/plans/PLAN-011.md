# PLAN-011：优化 Agent 发布、访问与分享体验

## 目标

让隐私确认操作只在当前知识库权限修订需要确认时出现，移除发布前独立生成和管理 Candidate Agent 链接的产品与 API 边界，并让 Candidate 在发布后直接访问 Agent、访客在公开页一键复制当前 Agent URL。

## 范围

本 Plan 覆盖隐私确认状态、Candidate Agent 发布区、公开 Agent 分享控件、专用链接生成 API 与服务、双语文案、长期产品合同、相关自动化及真实浏览器验收；保留历史 draft 发布兼容，不改变数据库结构、公开问答权限、Platform Admin 治理、Secret、部署或运行环境。
