# PLAN-022：优化公开 Agent 与预览会话体验

## 目标

让公开 Agent 的语言入口、右侧内容与推荐问题回归页面信息流并与 Candidate 预览保持一致，同时让 Candidate 能安全清空预览会话后重新调试 Agent。

## 范围

本 Plan 更新现有产品合同，调整公开 Agent 页眉、右侧栏和推荐问题，新增 owner 范围内的 Candidate preview 会话重置与确认交互，并完成自动化和真实浏览器验收；不改变公开游客身份、多会话、知识库、Agent 设置、发布状态、AI 用量或审计保留语义。
