# PLAN-005：闭环全界面视觉、双语与可访问性

## 目标

让七个 UI 参考主界面在真实数据和完整交互基础上达到桌面设计稿一致性，并在 iPhone 14 Pro Max 下保持可用，同时交付可持久化的 English / 简体中文与关键流程键盘可访问性。

## 范围

本 Plan 覆盖七张主界面参考图对应的 Candidate、公共 Agent 和共享入口，语言状态、核心界面与错误反馈、焦点和语义、桌面/移动 Chrome 验收；from-zero/restart、总可观测性与整个 Objective 的最终总验收不在本 Plan 内。

## Phase 1：视觉与交互合同

关联 Spec：[SPEC-001](../specs/SPEC-001.md)

- [ ] 1.1 对账七张主界面参考图、对应路由、关键几何和当前视觉差异
- [ ] 1.2 明确双语状态、持久化、SSR 一致性和键盘可访问性的最小系统设计

## Phase 2：双语闭环

- [ ] 2.1 实现匿名与登录后界面共用的语言选择和持久化合同
- [ ] 2.2 覆盖核心页面、操作反馈、空态和错误状态的 English / 简体中文文案

## Phase 3：视觉与可访问性闭环

- [ ] 3.1 对齐七个主界面在 1448 × 1086 下的结构、视觉语言和关键几何
- [ ] 3.2 保证 iPhone 14 Pro Max 下导航、表单、隐私控制和 Chat 无横向溢出且可完成操作
- [ ] 3.3 完成登录、导航、上传、筛选、隐私和 Chat 的键盘、焦点、label 与非颜色状态表达

## Phase 4：验证与收口

- [ ] 4.2 完成七界面桌面截图对照及移动、键盘、语言切换的真实 Chrome E2E
- [ ] 4.3 完成 Change Review、UI/I18N AC、索引、Progress 与原子 Commit 对账
