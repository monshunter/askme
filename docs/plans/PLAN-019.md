# PLAN-019：闭环公开身份补全与 Agent 发布可达性

## 目标

让现有及新注册 Candidate 都能从 Agent 发布阻塞项直达公开身份编辑，补齐真实职业头衔后返回并成功发布，同时保持发布前身份校验与公共资料真实性。

## 范围

更新现有产品合同与系统设计，交付 Candidate 公开资料编辑边界、发布 readiness 修复入口、双语反馈和账号隔离，并在保留本地数据的前提下完成目标账号、新注册账号与已完整账号的自动化及真实浏览器验收。自动生成职业头衔、放宽发布前置条件、修改 Interviewer 解锁语义和生产基础设施不在本 Plan 范围内。

- [x] 1.2 更新并审查公开资料写入、导航、授权与发布状态设计（[DESIGN-001](../architecture/DESIGN-001.md)）

- [x] 2.2 交付账号公开资料表单、发布阻塞项直达与双语反馈

## Phase 3：验收与收口

- [x] 3.3 对账正式制品、Progress 与 Git 并关闭交付
