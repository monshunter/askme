# PLAN-018：闭环邮件公开域名与游客多会话管理

## 目标

让密码重置与 Admin 邀请邮件统一使用可配置的公开域名，并让同一浏览器游客在单个公开 Agent 下新增、删除、切换和恢复多个独立会话。

## 范围

更新现有产品合同和系统设计，交付配置、Migration、公开 Session API、公开页会话侧栏与双语响应式交互，并在保留本地数据的前提下完成自动化、真实邮件和真实浏览器验收。Candidate 预览会话、会话改名、账号间同步和生产发布不在本 Plan 范围内。
