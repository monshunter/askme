# Journal 工作区

## 目的

保存交付过程、关键决策、验证结果、未完成项和可恢复上下文。

## 制品与命名

- Journal 默认按日期或稳定工作单元命名，并引用对应 Plan、Spec、Bug 和提交。
- 只记录可复核事实，不复制大段日志或伪造未运行的验证。

## 生命周期与归档

Journal 为追加式历史记录；更正时保留原结论及修订原因。

## 负责的 Skills

`autogo-change-close`、`autogo-work-continue`。

## INDEX 维护

Agent 在新增或更正 Journal 后同步维护 `INDEX.md`。
