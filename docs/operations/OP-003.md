## Reconcile 事件

1. 设计稿推荐问题最初使用整句 PostgreSQL FTS AND 语义，导致数据生成的问题无法命中对应证据。检索改为去除问句样板词后的有界 OR token，并移除无资料时的静态通用推荐；真实推荐问题随后返回 42% 回答与 Citation。
2. migration `0010` 把 `source_invalidated_at` 加到 `messages`，Drizzle schema 却错误声明在 `materials`，导致真实上传返回 207。字段 owner 已移回 `messages`，新增 schema ownership 回归测试，并让上传反馈显示失败文件与服务端原因。
3. Public Chat 对任意“当前检索为 0”的问题复用上一问证据，可能让独立问题借用无关项目。现在只有含明确上下文指代的追问可以复用上一轮证据；完整 Public Chat smoke 验证真实追问仍成功、独立无证据问题返回 `INSUFFICIENT_EVIDENCE`。
4. 一次同时构建 web/worker/migrate 的 Compose Bake 在本机并行执行相同 Next build，受其他项目容器资源占用影响异常缓慢。该仅构建操作被安全中止，运行中 Askme 容器与数据卷未变化；随后按 web → worker → migrate 串行构建成功。
