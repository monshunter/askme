# Specs 工作区

## 目的

保存可审阅、可验收的行为与质量契约。

## 制品与命名

- 正式制品使用 `SPEC-<编号>.md`，并记录稳定 AC ID。
- Spec 必须在正文链接唯一父 Plan；没有真实需求时不创建占位 Spec。

## 生命周期与归档

使用 `draft → review → approved → superseded/archive`；被替代内容保留历史指向。

## 负责的 Skills

`autogo-spec-write`、`autogo-spec-review`。

## INDEX 维护

Agent 在创建、更新或归档 Spec 后同步维护 `INDEX.md`。
