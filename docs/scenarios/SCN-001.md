# SCN-001：Candidate Agent 单一入口与发布闭环

状态：`verified`

关联 Plan：[PLAN-009](../plans/PLAN-009.md)

关联验收：[SPEC-001 `AC-AGENT-004`、`AC-UI-004`、`AC-UI-005`、`AC-UI-006`](../specs/SPEC-001.md)

## 用户结果

Candidate 只通过 Agent / 智能体一级入口完成预览、设置和发布管理；Workspace 不再显示快捷操作、邀请面试或独立发布入口，旧发布页面不可访问。语言切换在登录前后都只由右上角全局控件提供，页面、footer 与账号菜单没有第二入口；英文品牌保持 Askme，中文品牌统一为“职问”。

## 交互上下文

- 角色：本地 Candidate fixture
- 环境：已通过生产构建的本地 Web、健康 PostgreSQL 与 worker；入口由 `ASKME_BASE_URL` 指定
- 浏览器：Codex in-app Browser；本地隔离页面不依赖用户个人浏览器会话
- Viewport：桌面 `1448 × 1086`，移动 `430 × 932`
- Fixture：`npm run e2e:fixture -- prepare`；登录信息由项目 fixture owner 提供，不写入 Scenario Evidence
- 自动化入口：`npm run smoke:publication` 覆盖同一 publication API、登录/Agent/公共页 SSR 的全局唯一语言入口与旧路由 404；`global-language-switcher-contract.test.ts` 证明只有 Root Layout 渲染组件

## 前置状态

1. 当前 revision 已通过 `next build` 并由本地 Web 进程运行，db/web ready、worker running。
2. Candidate fixture 已重建，包含一份 `public_preview` 的 indexed 资料和可用公开身份，尚未确认当前隐私策略、未发布 Agent。
3. 浏览器从干净的 fixture 登录开始，不复用其他 Candidate 状态。

## 步骤与预期

1. 未登录访问 `/login`，在右上角将 English 切换为简体中文，再切回 English。
   - 页面可见且只可见一个语言选择控件，位置位于 viewport 右上角；切换刷新后登录页文案与 `<html lang>` 一致。
   - 登录卡片内部没有第二入口，切换不要求登录且不改变当前 URL。
   - wordmark 显示 Askme / 职问，页面不显示旧中文品牌“问候”。
2. 登录 Candidate 后打开 `/workspace/agent`。
   - 一级导航只有 Dashboard、Upload Materials、Knowledge Base、Privacy Control、Agent；页面 `h1` 为 `Agent`。
   - 顶栏不存在 Quick Action，侧栏不存在 Invite Interviewers 与 Publish Agent。
   - 账号菜单只有 Candidate 身份信息与 Sign out；页面 footer 没有语言入口，右上角全局控件仍是页面唯一实例。
   - Candidate wordmark 与 hero 印章显示“职问”，不存在旧中文品牌。
3. 检查 Agent 页面问答、settings 和发布区域。
   - 页面同时显示预览对话、Answer Tone/Public Mode/Privacy-Safe Mode 与当前数据库计算的发布 readiness。
   - 未确认隐私时发布动作被阻断并指向 Privacy Control。
4. 在 Privacy Control 确认当前策略后返回 Agent 页面并发布。
   - readiness 变为 Ready to publish，Publish Agent 可操作。
   - 发布成功后同页出现 opaque share link、Published、Open Public Page 与 Revoke Access，Public Mode 同步显示 On。
5. 打开公开页后返回 Agent 页面并撤销访问。
   - 公开页使用 Interviewer 权限且能显示 fixture 的公开身份；右上角仍只有同一个全局语言控件，public footer 没有第二入口，wordmark 与 hero 印章显示“职问”。
   - 撤销确认可由键盘/按钮完成；撤销后旧公开链接不可用。
6. 使用右上角全局控件切换为简体中文，并以 `430 × 932` 检查 Agent 页面。
   - 一级导航和 `h1` 使用“智能体”；Shell 仍没有“快捷操作”“邀请面试官”“发布 Agent”一级入口。
   - 全局控件不与 drawer、搜索、头像或页面操作重叠；`documentElement.scrollWidth` 不超过 `innerWidth`，主要问答、设置与发布区域可纵向访问。
7. 直接访问 `/workspace/publish`、`/workspace/publish/preview` 与 `GET /api/publications/preview`。
   - 两个旧页面和专用 Candidate 公共预览 API 均返回 404，不渲染旧发布 UI，也不保留无消费者的旧后端。

## 观测与失败判定

- 记录页面可见文本、导航链接、语言控件数量与 bounding rect、viewport、顶栏交叠和横向 overflow。
- 检查运行期间新增的 console error/warning 与失败网络请求；预期旧路由 404 除外。
- 任一页面出现第二语言入口、全局控件不在右上角或与顶栏重叠、旧中文品牌“问候”仍作为品牌标记可见、重复 Candidate 入口仍可见、发布生命周期离开 Agent 页面、旧路由非 404、发布/撤销/Public Mode 状态不一致或移动端横向溢出均为 `FAIL`。

## 清理与恢复

- 执行 `npm run e2e:fixture -- cleanup` 删除本场景 Candidate 及级联 publication、conversation、material 与 knowledge 状态。
- 保留 `askme-local` 容器与既有 volumes，不 reset、不删除其他本地用户数据。
