# Askme Product Specification v0.2

Boundary ID：`askme-product-direction`

Owner boundary：Askme 的长期产品定位、角色价值、MVP 能力范围和一级信息架构。

Status：`active`

> 产品代号：Askme\
> 中文名称：职问\
> 产品定位：个人职业知识库 Agent（Personal Career Knowledge Agent）\
> 核心理念：Don't browse my resume. Ask my Agent.

------------------------------------------------------------------------

# 1. 产品概述

## 1.1 背景

传统招聘依赖静态简历，但简历无法完整表达候选人的真实能力：

-   复杂项目经历难以展开；
-   技术深度无法通过几页 PDF 展示；
-   高级工程师的系统设计能力、工程判断和长期积累难以验证；
-   招聘方没有足够时间阅读大量资料。

与此同时，AI 时代大量简历、求职信和项目描述开始被 AI
生成，导致文本越来越同质化。

Askme 的目标不是生成更漂亮的简历，而是：

> 将个人职业资产转化为一个可以被自然语言访问的职业 Agent。

------------------------------------------------------------------------

# 2. 产品定位

## 一句话定义

Askme 是一个个人职业知识库 Agent。

候选人上传自己的职业资料，AI
自动构建个人职业知识库，并生成一个可交互的职业
Agent。面试官无需浏览简历或资料，只需要通过自然语言提问，即可了解候选人的经历、能力、项目实践，并获得回答依据。

------------------------------------------------------------------------

# 4. 用户角色

Askme 只有两个核心角色。

------------------------------------------------------------------------

# 4.1 Candidate（候选人 / Owner）

Candidate 是职业 Agent 的唯一拥有者。

负责：

-   提供职业资料；
-   管理知识库；
-   控制公开范围；
-   发布自己的 Agent。

Candidate 不是招聘系统用户，而是职业资产拥有者。

------------------------------------------------------------------------

## Candidate 权限

### 职业知识库管理

支持导入：

-   简历；
-   项目文档；
-   GitHub Repository；
-   技术文章；
-   架构设计文档；
-   开源贡献；
-   个人总结。

------------------------------------------------------------------------

### Agent 管理

Candidate 可以：

-   创建 Agent；
-   预览 Agent 回答；
-   设置隐私边界；
-   发布访问链接；
-   撤销访问。

------------------------------------------------------------------------

# 4.2 Interviewer（面试官）

统一包含：

-   HR；
-   Recruiter；
-   Hiring Manager；
-   技术面试官。

他们的共同目标：

> 通过 Agent 快速理解候选人的职业经历和能力。

------------------------------------------------------------------------

## Interviewer 权限

可以：

-   打开候选人 Agent；
-   进行自然语言提问；
-   获取项目解释；
-   获取能力匹配分析；
-   查看回答引用来源。

不能：

-   修改候选人资料；
-   浏览完整知识库；
-   获取未授权信息。

------------------------------------------------------------------------

# 5. 核心交互模型

## Interviewer Experience

Agent First。

不是：

    Profile
    Projects
    Skills
    Evidence

而是：

    Chat Interface

示例：

用户：

> 介绍一下这个候选人的 AI Agent 经验。

Agent：

> 根据候选人授权资料，他主要有三个方向：
>
> 1.  Coding Agent Engineering
> 2.  Harness Engineering
> 3.  AI Infra Platform Engineering
>
> 我可以进一步展开任意项目。

------------------------------------------------------------------------

# 6. Personal Career Knowledge Base

Askme 的核心资产不是简历，而是个人职业知识库。

类似企业知识库：

    Enterprise Knowledge Base

    产品文档
    技术文档
    Wiki
    SOP

Askme：

    Personal Career Knowledge Base

    简历
    工作经历
    项目资料
    代码仓库
    技术方案
    文章
    作品
    个人总结

------------------------------------------------------------------------

## 特点

-   Candidate 拥有；
-   Agent 可读取；
-   默认不直接暴露；
-   用于回答问题。

------------------------------------------------------------------------

# 7. Source Material 与 Citation

## Source Material

候选人上传的资料称为：

Source Material。

例如：

-   project-design.md
-   GitHub Repository
-   Architecture Document
-   Blog Article

这些是 Agent 的知识来源。

------------------------------------------------------------------------

## Citation

面试官看到的不是资料库，而是回答中的引用。

例如：

问题：

> 他是否真实做过 Kubernetes Operator？

回答：

    候选人在 Kubernetes Operator Platform 项目中负责：

    - CRD 设计
    - Controller 开发
    - Reconcile Loop 优化

    参考来源：
    - Kubernetes Operator 项目总结文档
    - GitHub Repository
    - 架构设计文档

------------------------------------------------------------------------

# 9. MVP 范围

MVP 只验证一个核心闭环：

    候选人上传资料

    ↓

    生成职业知识库

    ↓

    生成 Candidate Agent

    ↓

    面试官聊天了解候选人

    ↓

    获得面试机会

------------------------------------------------------------------------

## Candidate MVP

包含：

1.  上传资料；
2.  AI整理职业知识库；
3.  审核公开内容；
4.  在 Agent 中管理发布与分享。

------------------------------------------------------------------------

## Interviewer MVP

包含：

1.  打开 Agent；
2.  Chat；
3.  推荐问题；
4.  回答引用来源。

------------------------------------------------------------------------

# 10. 明确不做

MVP 不做：

-   企业 ATS 集成；
-   Recruiting Agent API；
-   招聘自动筛选；
-   候选人评分；
-   自动录用/淘汰；
-   面试作弊；
-   复杂企业后台。

    ↓

    生成 PDF

    ↓

    ↓

------------------------------------------------------------------------

# 14. 最终产品定义

Askme 不是：

-   AI 简历工具；
-   招聘 SaaS；
-   企业招聘 Agent。

Askme 是：

> 一个让个人职业资产被 AI 理解、组织和表达的职业知识库 Agent。

核心价值：

> 从"投递一份简历"升级为"投递一个可以回答问题的职业 Agent"。
